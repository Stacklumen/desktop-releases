# Stacklumen Desktop

Installers for Stacklumen Desktop, the workbench for Stacklumen sites, clients and code.

**Download from [stacklumen.com/download](https://www.stacklumen.com/download)** — sign in to your Stacklumen account to get the build for your Mac or Windows PC.

This repository holds release files only. Each release lists the SHA-256 fingerprint of every file; the download page shows the same fingerprints, so a copy can be checked against them.

The app is in private alpha and not yet code-signed:

- **macOS:** the first time, right-click Stacklumen in Applications and choose **Open**.
- **Windows:** if SmartScreen says “Windows protected your PC”, choose **More info → Run anyway**.

Questions: support@stacklumen.com
